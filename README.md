# Lumina Electric Air — ระบบประเมินผล

ระบบประเมินผลแบบสาธารณะสำหรับโครงงาน "Lumina Electric Air" มี 2 ส่วน:

1. **Frontend** (`/lumina-evaluation`) — เว็บไซต์ที่ผู้ประเมินกรอกแบบสอบถาม + หน้าแดชบอร์ดผลสรุป อัปโหลดขึ้น GitHub Pages ได้เลย
2. **Backend** (`/google-apps-script`) — Google Apps Script ที่เก็บข้อมูลลง Google Sheets และคำนวณสถิติสะสม

```
/lumina-evaluation
  index.html        แบบประเมิน (เลือกประเภทผู้ประเมิน → ข้อมูลทั่วไป → 10 ข้อ → ส่ง)
  results.html       แดชบอร์ดผลสรุป (ต้องใส่รหัสผ่าน)
  styles.css         ธีมภาพรวม (สีฟ้า Lumina, การ์ดโค้งมน, sparkle)
  config.js          <<< ใส่ URL ของ Apps Script ที่นี่ที่เดียว
  questions.js        คำถามทั้งหมด (ใช้ร่วมกันทั้งหน้าแบบประเมินและแดชบอร์ด)
  script.js           ตรรกะของแบบประเมิน
  results.js          ตรรกะของแดชบอร์ด
/google-apps-script
  Code.gs             โค้ด backend ทั้งหมด (วางในบรรณาธิการ Apps Script)
```

---

## สถานะโครงงาน (อ่านก่อน)

**สิ่งที่ทำเสร็จแล้วและทดสอบแล้ว (ในสภาพแวดล้อมนี้ ไม่มีเครือข่ายอินเทอร์เน็ต จึงทดสอบได้เฉพาะส่วนที่ไม่ต้องเชื่อมต่อ Google จริง):**
- ตรรกะการคำนวณสถิติทั้งหมด (N, คะแนนรวม, คะแนนเต็มแบบไดนามิก, ร้อยละ, ค่าเฉลี่ย, S.D. แบบ sample, การแปลผลระดับความพึงพอใจ) — ทดสอบด้วยชุดข้อมูลจำลองใน Node.js รวมถึงตัวอย่างตัวเลขจากโจทย์ (30 คน คะแนนเต็ม 1,500 คะแนนจริง 1,320 = 88%) และเคสสะสม 30 → 35 คน ผลลัพธ์ถูกต้องตรงกันทุกกรณี โค้ดชุดเดียวกันนี้ถูกฝังอยู่ใน `Code.gs` โดยตรง (ตรวจสอบแล้วว่าตรงกัน)
- โค้ด JavaScript ทุกไฟล์ (`script.js`, `results.js`, `questions.js`, `config.js`, `Code.gs`) ผ่านการตรวจสอบไวยากรณ์แล้ว ไม่มี syntax error
- โครงสร้าง HTML ผ่านการตรวจสอบว่าแท็กเปิด-ปิดครบถ้วน

**สิ่งที่ยังไม่ได้ทดสอบ (เพราะสภาพแวดล้อมนี้ไม่มีการเชื่อมต่ออินเทอร์เน็ต จึงเปิด Google Sheets / Apps Script จริงไม่ได้):**
- การเชื่อมต่อจริงระหว่างเว็บไซต์ ↔ Apps Script ↔ Google Sheets
- การกดปุ่มจริงบนเบราว์เซอร์ (คลิก, sparkle effect, การแสดงผลบนมือถือจริง)
- Deploy เป็น Web App จริง

**สิ่งที่คุณต้องทำเอง (ไม่มีทางเลี่ยงได้ เพราะต้องใช้บัญชี Google ของคุณ):**
- สร้าง Google Sheet และ deploy Apps Script (ขั้นตอนอยู่ด้านล่าง)
- ตั้งรหัสผ่านสำหรับ "สำหรับอาจารย์" / "สำหรับเจ้าของโครงงาน"
- นำ URL ของ Apps Script มาใส่ใน `config.js`
- ทดสอบระบบจริงตามเช็กลิสต์ท้ายเอกสารนี้ก่อนใช้งานจริง

อย่าเชื่อว่า "เชื่อมต่อ Google Sheets สำเร็จแล้ว" จนกว่าคุณจะกดส่งแบบประเมินจริง 1 ชุด แล้วเห็นแถวใหม่ปรากฏใน Google Sheet ด้วยตาตัวเอง

---

## ขั้นตอนที่ 1: สร้าง Google Sheet

1. ไปที่ [sheets.google.com](https://sheets.google.com) แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อว่า เช่น `Lumina Evaluation Data`
2. ไม่ต้องสร้างชีตย่อยหรือใส่หัวตารางเอง — Apps Script จะสร้างชีตชื่อ `Responses` พร้อมหัวตารางให้อัตโนมัติในการรันครั้งแรก

## ขั้นตอนที่ 2: วาง Apps Script

1. ในสเปรดชีตที่สร้าง ไปที่เมนู **Extensions (ส่วนขยาย) → Apps Script**
2. จะเปิดหน้าต่างแก้ไขโค้ด มีไฟล์ `Code.gs` อยู่แล้ว (มีโค้ดตัวอย่าง `function myFunction() {}`)
3. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาทั้งหมดจากไฟล์ `google-apps-script/Code.gs` ที่ให้มา
4. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)
5. ตั้งชื่อโปรเจกต์ เช่น `Lumina Backend`

## ขั้นตอนที่ 3: ตั้งรหัสผ่านสำหรับดูแดชบอร์ด

1. ในหน้า Apps Script editor ไปที่ไอคอนรูปเฟือง **Project Settings (การตั้งค่าโปรเจกต์)** ทางแถบซ้าย
2. เลื่อนลงมาหา **Script Properties (พร็อพเพอร์ตี้สคริปต์)** → กด **Add script property**
3. เพิ่ม 2 รายการ:
   - `TEACHER_PASSCODE` = รหัสผ่านที่คุณตั้งเองสำหรับ "สำหรับอาจารย์" เช่น `lumina-teacher-2026`
   - `OWNER_PASSCODE` = รหัสผ่านที่คุณตั้งเองสำหรับ "สำหรับเจ้าของโครงงาน" เช่น `lumina-owner-2026`
4. กด **Save script properties**

> รหัสผ่านนี้จะไม่ปรากฏอยู่ในโค้ดฝั่งเว็บไซต์เลย จึงปลอดภัยกว่าการฝังรหัสผ่านไว้ใน JavaScript ตรง ๆ แต่ข้อจำกัดคือมันเป็นรหัสผ่านร่วมชุดเดียว ไม่ใช่ระบบล็อกอินรายบุคคล — เหมาะสำหรับป้องกันการเข้าถึงโดยไม่ได้ตั้งใจในระดับโครงงานของนักศึกษา ไม่ได้ออกแบบมาเพื่อป้องกันผู้บุกรุกที่ตั้งใจโจมตีระบบจริงจัง

## ขั้นตอนที่ 4: Deploy เป็น Web App

1. ที่มุมขวาบนของหน้า Apps Script editor กด **Deploy → New deployment**
2. กดไอคอนรูปเฟืองข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - **Execute as**: `Me` (บัญชีของคุณ)
   - **Who has access**: `Anyone` (เพื่อให้ผู้ประเมินที่ไม่มีบัญชี Google ก็ส่งแบบประเมินได้)
4. กด **Deploy**
5. ระบบจะขอให้คุณ **Authorize access** — กด **Authorize access** แล้วเลือกบัญชี Google ของคุณ จะมีหน้าคำเตือน "Google hasn't verified this app" (เพราะเป็นสคริปต์ของคุณเอง ไม่ใช่แอปที่ผ่านการรีวิวจาก Google) ให้กด **Advanced → Go to [ชื่อโปรเจกต์] (unsafe)** แล้วกด **Allow**
6. หลัง deploy สำเร็จ จะได้ **Web app URL** รูปแบบ `https://script.google.com/macros/s/xxxxxxxxxxxx/exec` — **คัดลอก URL นี้ไว้**

> ถ้าแก้โค้ดใน `Code.gs` ภายหลัง ต้องกด **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → เลือก Version: New version → Deploy** ทุกครั้ง ไม่เช่นนั้นเว็บไซต์จะยังเรียกใช้โค้ดเวอร์ชันเก่าอยู่

## ขั้นตอนที่ 5: ตั้งค่า Frontend

1. เปิดไฟล์ `lumina-evaluation/config.js`
2. แทนที่ `"PASTE_YOUR_DEPLOYED_WEB_APP_URL_HERE"` ด้วย URL ที่ได้จากขั้นตอนที่ 4 เช่น:
   ```js
   const LUMINA_CONFIG = {
     APPS_SCRIPT_URL: "https://script.google.com/macros/s/xxxxxxxxxxxx/exec"
   };
   ```
3. บันทึกไฟล์

## ขั้นตอนที่ 6: ทดสอบการเชื่อมต่อ

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (หรือรันผ่าน local server / เปิดผ่าน GitHub Pages ก็ได้)
2. เลือก "ลูกค้า" หรือ "ช่าง" → กรอกข้อมูลทั่วไป → ตอบครบ 10 ข้อ → กด "ส่งแบบประเมิน"
3. ถ้าขึ้นหน้าขอบคุณ แปลว่าส่งสำเร็จ — เปิด Google Sheet ของคุณ ควรเห็นแถวใหม่ในชีต `Responses`
4. ถ้าขึ้นข้อความ error สีแดง ให้ตรวจสอบ:
   - URL ใน `config.js` ถูกต้องหรือไม่ (ไม่มีช่องว่างเกิน ไม่ตกหล่นตัวอักษร)
   - Deploy เป็น "Anyone" จริงหรือไม่ (ไม่ใช่ "Only myself")
   - เปิด Developer Console (F12) ดู error message เพิ่มเติม
5. เปิด `results.html` → กด "สำหรับอาจารย์" หรือ "สำหรับเจ้าของโครงงาน" → กรอกรหัสผ่านที่ตั้งไว้ในขั้นตอนที่ 3 → ควรเห็นสถิติของข้อมูลที่เพิ่งส่งไป

## หลักการคำนวณสถิติ (สรุปสำหรับอาจารย์)

- **คะแนนเต็มคำนวณจาก N แบบไดนามิก**: `10 ข้อ × 5 คะแนน × N` — ไม่มีการฝังค่า 30 ไว้ตายตัวที่ใดในระบบเลย ทดสอบแล้วว่าเมื่อ N เปลี่ยนจาก 30 เป็น 35 ตัวเลขทุกตัวคำนวณใหม่ถูกต้อง
- **ข้อมูลสะสมตลอดเวลา**: Apps Script อ่านค่าจากทุกแถวในชีต `Responses` ทุกครั้งที่มีการขอสถิติ ไม่มีการลบข้อมูลเก่า และไม่มีการคำนวณจากเฉพาะการส่งครั้งล่าสุด
- **S.D.**: ใช้สูตร Sample Standard Deviation (หารด้วย n−1) ทั้งสองระดับ แต่คำนวณจากข้อมูลคนละชุด — **S.D. รายข้อ** คำนวณจากคำตอบของผู้ตอบทุกคนในข้อนั้น ๆ ข้อเดียว ส่วน **S.D. รวม** คำนวณจาก "คะแนนรวมต่อคน" (ผลรวม 10 ข้อของแต่ละคน มีค่า 10–50) ไม่ใช่จากคำตอบรายข้อทั้งหมดที่นำมารวมกัน
- คำอธิบายละเอียดพร้อมสูตรทุกตัวแสดงอยู่ในหน้า `results.html` ส่วน "วิธีการคำนวณ" อยู่แล้ว (ภาษาไทย)

## เช็กลิสต์ทดสอบก่อนใช้งานจริง

ทำเครื่องหมายด้วยตัวเองหลังทดสอบแต่ละข้อ:

- [ ] เลือก "ลูกค้า" แล้วเห็นคำถามชุดลูกค้า
- [ ] เลือก "ช่าง" แล้วเห็นคำถามชุดช่าง
- [ ] ข้อมูลทั่วไปแสดงคำถามครบ (รวมข้อเสริมตามประเภทผู้ประเมิน)
- [ ] ไม่สามารถกด "ถัดไป" ได้ถ้ายังตอบไม่ครบ (ทั้งหน้าข้อมูลทั่วไปและหน้าคำถาม)
- [ ] ตอบครบ 10 ข้อแล้วกดส่งสำเร็จ ขึ้นข้อความขอบคุณ
- [ ] เปิด Google Sheet เห็นแถวใหม่ พร้อม `evaluator_type` ถูกต้อง และ `total_score` ตรงกับผลรวมที่ตอบจริง
- [ ] ส่งอีกชุดหนึ่งด้วยประเภทผู้ประเมินอีกแบบ แถวเก่าที่เคยส่งยังอยู่ครบ ไม่ถูกลบ
- [ ] เปิด `results.html` กรอกรหัสผ่านผิด → ขึ้นข้อความแจ้งเตือน ไม่เข้าเห็นข้อมูล
- [ ] กรอกรหัสผ่านถูก → เห็นสถิติ N, คะแนนรวม, คะแนนเต็ม, ร้อยละ, ค่าเฉลี่ย, S.D., ระดับความพึงพอใจ
- [ ] N ที่แสดงตรงกับจำนวนแถวจริงในชีต (รวมทั้งลูกค้า+ช่าง)
- [ ] กดแท็บ "ลูกค้า" / "ช่าง" / "ทั้งหมด" แล้วตัวเลขเปลี่ยนถูกต้องตามกลุ่ม
- [ ] ทดลองปิดอินเทอร์เน็ตแล้วกดส่งแบบประเมิน → ขึ้นข้อความ error ภาษาไทย และคำตอบที่กรอกไว้ไม่หายไป
- [ ] เปิดเว็บไซต์บนมือถือจริง (หรือโหมดจำลองมือถือใน Chrome DevTools) → ปุ่มกดง่าย ไม่เล็กเกินไป
- [ ] คลิกคำตอบแบบ Likert แล้วเห็น sparkle กระจายจากจุดที่คลิก
- [ ] เอาเมาส์ชี้ปุ่มบนเดสก์ท็อป เห็น shine effect เบา ๆ
- [ ] ไม่มี emoji ปรากฏในคำถามหรือตัวเลือกคำตอบใด ๆ

## นำขึ้น GitHub Pages

อัปโหลดเฉพาะโฟลเดอร์ `lumina-evaluation/` ขึ้น repository ของคุณ (เช่นวางไว้ที่ root หรือโฟลเดอร์ `docs/`) แล้วเปิดใช้งาน GitHub Pages ใน Settings → Pages เลือก branch และโฟลเดอร์ที่ต้องการ ตัว `config.js` ที่ใส่ URL ของ Apps Script ไว้แล้วจะทำงานได้ทันทีบน GitHub Pages โดยไม่ต้องแก้ไขอะไรเพิ่ม โฟลเดอร์ `google-apps-script/` ไม่ต้องอัปโหลดขึ้น GitHub (มันอยู่ในระบบของ Google อยู่แล้ว) แต่เก็บไว้เป็นสำเนาสำรอง/ส่งอาจารย์ตรวจได้
